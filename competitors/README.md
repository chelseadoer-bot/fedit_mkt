# 경쟁사·참고 광고

- `brands.json`: 비교할 회사 목록. `keyword`는 메타 광고 라이브러리 검색어(한국·진행 중 광고)로 쓰입니다.
- 광고 스크린샷은 `회사slug/` 폴더에 올리면 매일 실행 때 Claude가 우리 소재와 같은 기준으로 라벨을 붙입니다.
- 파일 이름을 `2026-11-10_설명.jpg`처럼 날짜로 시작하면 "처음 본 날"로 표시됩니다.
  광고 라이브러리에서 오래 도는 광고(성과가 좋을 가능성이 큼)는 시작일을 적어 두면 비교에 도움이 됩니다.
- GitHub 웹에서 올리기: 저장소 → `competitors/회사slug` 폴더 → **Add file → Upload files**.
